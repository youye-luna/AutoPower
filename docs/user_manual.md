# AutoPower 用户操作手册

## 简介

AutoPower 是一款功能完整的 Windows 定时关机软件，提供直观的用户界面和强大的关机管理功能。本手册将详细介绍软件的使用方法、功能特性和常见问题解决方案。

## 功能特性

- ⏰ **精确时间设置**：支持设置具体的关机时间（精确到分钟）
- ⏱️ **实时倒计时**：显示剩余关机时间，实时更新
- ❌ **任务管理**：支持取消已设置的关机任务
- 🔔 **智能提醒**：关机前5分钟自动显示提醒窗口
- 🛡️ **错误处理**：完善的错误处理机制，提供清晰的错误提示
- 🎯 **快捷操作**：提供15分钟、30分钟、1小时、2小时的快速设置按钮
- 💡 **状态显示**：实时显示任务状态和系统信息

## 系统要求

- **操作系统**：Windows 10 / Windows 11
- **内存**：至少 512MB RAM
- **硬盘空间**：至少 10MB 可用空间
- **权限**：需要管理员权限执行关机操作

## 安装说明

### 自动安装
1. 下载 AutoPower 安装包
2. 双击运行安装程序
3. 按照安装向导完成安装
4. 启动 AutoPower 程序

### 手动安装
1. 下载 AutoPower 压缩包
2. 解压到任意目录
3. 双击运行 `AutoPower.exe`
4. 首次运行时可能需要管理员权限

### 界面元素说明

#### 1. 时间设置区域
- **关机时间选择器**：点击可弹出时间选择器，选择具体关机时间
- **设置关机按钮**：点击后设置选定的关机时间
- **提示信息**：显示操作提示和说明

#### 2. 倒计时显示区域
- **倒计时标签**：显示剩余关机时间
  - 正常状态：黑色显示
  - 警告状态（<1小时）：橙色显示
  - 紧急状态（<1分钟）：红色显示
  - 关机时间到：红色闪烁显示

#### 3. 快速设置区域
- **15分钟后**：快速设置15分钟后关机
- **30分钟后**：快速设置30分钟后关机
- **1小时后**：快速设置1小时后关机
- **2小时后**：快速设置2小时后关机

#### 4. 状态信息区域
- **状态标签**：显示当前任务状态信息
- **取消关机按钮**：取消已设置的关机任务（仅在有任务时可用）

## 使用方法

### 基本操作

#### 1. 设置关机时间

**方法一：使用时间选择器**
1. 点击时间选择器（显示当前时间的框）
2. 在弹出的时间选择器中选择目标时间
3. 点击"设置关机"按钮
4. 等待确认提示

**方法二：使用快速设置按钮**
1. 点击所需的快速设置按钮（15分钟、30分钟、1小时、2小时）
2. 系统会自动计算并设置关机时间
3. 等待确认提示

**方法三：手动输入时间**
1. 点击时间选择器
2. 直接输入时间（格式：HH:mm）
3. 点击"设置关机"按钮

#### 2. 查看倒计时
- 设置成功后，倒计时区域会显示剩余关机时间
- 倒计时每秒更新一次
- 窗口标题会显示"关机已设置"状态

#### 3. 取消关机任务
1. 确认有关机任务在进行中
2. 点击"取消关机"按钮
3. 等待确认提示
4. 取消成功后，倒计时显示会重置

### 高级功能

#### 1. 关机提醒
- 关机前5分钟会自动弹出提醒窗口
- 提醒窗口会显示警告信息
- 可以选择立即取消关机或继续等待

#### 2. 任务状态管理
- **状态显示**：实时显示当前任务状态
- **自动更新**：状态信息会根据任务情况自动更新
- **错误提示**：出现错误时会显示详细的错误信息

#### 3. 错误处理
- **权限错误**：提示需要管理员权限
- **时间错误**：提示无效的时间格式或值
- **系统错误**：提示系统调用失败信息
- **冲突处理**：处理任务冲突和重复设置

## 注意事项

### 权限要求
- 关机操作需要管理员权限
- 如果遇到"权限不足"错误，请以管理员身份运行程序
- 右键点击程序图标，选择"以管理员身份运行"

### 时间设置
- 时间格式为 HH:mm（24小时制）
- 支持的时间范围：00:00 - 23:59
- 如果设置的时间已过去，会自动设置为第二天

### 系统兼容性
- 支持 Windows 10 和 Windows 11
- 不支持 Windows 7 及更早版本
- 确保系统已安装最新的系统更新

### 数据安全
- 关机前请保存所有重要工作
- 关机提醒窗口出现时，请立即保存数据
- 建议在关机前手动保存重要文件

## 常见问题

### 1. 程序无法启动
**问题**：双击程序图标后没有反应
**解决方法**：
- 检查是否已安装 Qt 运行库
- 尝试以管理员身份运行
- 检查系统是否满足最低要求
- 查看错误日志信息

### 2. 无法设置关机时间
**问题**：点击"设置关机"后没有反应或提示错误
**解决方法**：
- 确保以管理员身份运行程序
- 检查输入的时间格式是否正确
- 确认没有其他关机任务在进行中
- 查看具体的错误信息

### 3. 倒计时显示异常
**问题**：倒计时显示不正确或停止更新
**解决方法**：
- 重新设置关机时间
- 检查系统时间是否正确
- 重启程序
- 检查是否有其他程序干扰

### 4. 关机提醒不工作
**问题**：关机前没有弹出提醒窗口
**解决方法**：
- 确保程序正在运行
- 检查系统通知设置
- 重启程序
- 查看程序是否被其他程序阻止

### 5. 无法取消关机任务
**问题**：点击"取消关机"后任务仍在进行
**解决方法**：
- 确保有关机任务在进行中
- 尝试多次点击"取消关机"
- 重启程序后再次尝试
- 使用系统命令取消关机

## 快捷键

### 全局快捷键
- **Ctrl+S**：设置关机时间
- **Ctrl+C**：取消关机任务
- **Ctrl+Q**：退出程序

### 界面快捷键
- **Enter**：确认当前操作
- **Esc**：取消当前操作
- **Tab**：切换界面焦点

## 系统集成

### 开机自启动
1. 将程序快捷方式复制到以下目录：
   ```
   C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup
   ```
2. 或使用任务计划程序设置开机自启动

### 命令行参数
```
AutoPower.exe /time 22:30     # 设置关机时间为22:30
AutoPower.exe /cancel         # 取消关机任务
AutoPower.exe /status         # 查看当前状态
```

## 故障排除

### 日志查看
程序运行时会生成日志文件，位置如下：
```
%APPDATA%\AutoPower\logs\
```

### 重置设置
如果程序出现异常，可以尝试重置设置：
1. 关闭程序
2. 删除配置文件：
   ```
   %APPDATA%\AutoPower\config.ini
   ```
3. 重新启动程序
